Two hypotheses that travel together

An index-set product needs almost all factors equal to e, so the product is finite, and it needs G commutative, so the order does not matter. Drop either and the symbol stops meaning anything. This pairing reappears at direct sums in §7.

Subsets

For subsets S, S′ of a monoid G, Lang writes SS′ for the set of all products xy with x ∈ S and y ∈ S′ (p. 6). This is associative, and GG = G because G has a unit. Write xS for {x}S.
