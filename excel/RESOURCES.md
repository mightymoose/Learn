# Excel Resources

Every link below was checked on 2026-08-14. The check method is named on each entry,
because two of them refuse automated fetches. If you find a dead link, delete it rather
than leaving it here.

## Knowledge

- [Excel help and learning (Microsoft)](https://support.microsoft.com/en-us/excel)
  *Fetched and read.* The official hub. Sections for getting started, formulas and
  functions, importing and analysing, formatting, and troubleshooting. Use for: the
  first answer on any feature question, because it states version availability.

- [Excel functions by category (Microsoft)](https://support.microsoft.com/en-us/office/excel-functions-by-category-5f91f4e9-7b42-46d2-9bd1-63f26a86c0eb)
  *Fetched and read.* Every built-in function, grouped into 15 categories. Use for:
  finding the right function when you can only describe what you want.

- [XLOOKUP function (Microsoft)](https://support.microsoft.com/en-us/office/xlookup-function-b7fd680e-6d10-43e6-84f9-88eae8bf5929)
  *Fetched and read.* Gives the full signature and, importantly, the version list.
  XLOOKUP is in Microsoft 365, 2021 and 2024. It is **not** in Excel 2016 or 2019.
  Use for: settling the version question before tier 2 is written.

- [Excel specifications and limits (Microsoft)](https://support.microsoft.com/en-us/office/excel-specifications-and-limits-1672b34d-7043-467e-8e27-269d656771c3)
  *Fetched and read.* A worksheet holds 1,048,576 rows by 16,384 columns. Use for:
  the moment a lesson has to say "this is the point where Excel is the wrong tool".

- [Exceljet function reference](https://exceljet.net/functions)
  *Fetched and read.* 433 functions across 13 categories, each with syntax, worked
  examples and usage notes. Independent site, not Microsoft. Use for: a worked example
  when the Microsoft page gives only the signature.

- [Power Query documentation (Microsoft Learn)](https://learn.microsoft.com/en-us/power-query/)
  *Fetched and read.* Covers getting data, shaping it, query folding, diagnostics and
  error handling. Use for: tier 4. Note that Power Query on Mac is behind Windows.

- [DAX reference (Microsoft Learn)](https://learn.microsoft.com/en-us/dax/)
  *Fetched and read.* The language used by measures in Power Pivot. Covers syntax,
  operators, functions and a glossary. Use for: tier 4, once the data model appears.

## Wisdom (Communities)

- [MrExcel Message Board](https://www.mrexcel.com/board/)
  *Checked by search, not fetched. The board returns 403 to automated fetchers.* Search
  results on 2026-08-14 report 442,000 members, 2 million threads and 6 million posts.
  Covers formulas, PivotTables, Power Pivot and VBA. Use for: a hard formula problem
  where you can post a sample of the data.

- [r/excel](https://www.reddit.com/r/excel/)
  *Checked by search, not fetched. Reddit blocks the fetcher used here.* Confirmed
  active on 2026-08-14. Mixed skill levels, fast answers. Use for: a first question,
  and for seeing how other people phrase problems.

## Gaps

- **No verified structured course.** The Microsoft hub is a reference, not a sequence.
  The roadmap in this workspace is filling that gap itself.
- **No verified video source.** Video suits a beginner learning the interface. Named
  candidates exist, but none was checked in this session, so none is listed. Check one
  before a lesson recommends it.
- **Microsoft Tech Community could not be checked.** Its Excel category redirects to a
  Microsoft login, so the fetcher could not see it. It is likely fine. Confirm in a
  browser before adding it.
- **No Mac-specific source.** Power Query and Power Pivot differ on Mac. Tier 4 needs a
  source for this, or it needs to state the gap out loud.
