Course roadmap

Twenty lessons in four tiers, beginner to expert. Tier 1 is written. Open this page first, then work down.

How to use this page

Take the tiers in order. Each one assumes the one before it, so this is a dependency chain, not a menu. Do one lesson in a sitting, then leave it. Come back two days later and try the recall questions before rereading anything. That gap is where the learning actually happens.

Tier 1 · Foundations

What every later tier assumes. Nothing here depends on which Excel you have.

Written and ready

  1. Formulas, not numbersWritten
    Cell addresses, the formula bar, and why a typed number goes stale.
  2. The dollar signWritten
    Relative, absolute and mixed references. Fill one formula across a block correctly.
  3. TablesWritten
    Structured references and calculated columns. Data that knows how big it is.
  4. Answering questionsWritten
    SUMIFS, COUNTIFS, AVERAGEIFS, and a summary block that checks itself.

Tier 2 · Working analyst

Where a spreadsheet stops being a list and starts being an answer. This tier is where Excel versions start to differ, so lesson 5 waits on one question. See which Excel do you have below.

Planned

  1. Lookups: pulling a value out of another tablePlanned
    XLOOKUP if you have it, INDEX and MATCH if you do not. Both taught the same way.
  2. Logic: IF, IFS and catching errorsPlanned
    Branching without nesting six levels deep. IFERROR, and when hiding an error is wrong.
  3. Text and dates that arrive dirtyPlanned
    TRIM, TEXT, DATE and the reason a date sometimes shows as 45000.
  4. PivotTablesPlanned
    Summarising thousands of rows by dragging. What they do well, and what they hide.
  5. Charts that do not misleadPlanned
    Picking the right form, and the axis choices that quietly lie.
  6. Validation and conditional formattingPlanned
    Stopping bad data going in, and making the important number visible.

Tier 3 · Building models

The shift from answering one question to building something other people rely on.

Planned

  1. Dynamic arraysPlanned
    FILTER, SORT, UNIQUE and SEQUENCE. One formula that returns many cells.
  2. Model layout: inputs, calculations, outputsPlanned
    Where to put things so a stranger can follow. Named ranges, and the one-sheet rule.
  3. Auditing a workbook you did not writePlanned
    Trace precedents, evaluate formula, and finding the number that is quietly hardcoded.
  4. Scenarios and solving backwardsPlanned
    Goal Seek, data tables, and Solver. Asking what input gives this answer.

Tier 4 · Expert

The tools most Excel users never reach. This tier is where the ceiling actually is. Some of it is Windows only.

Planned

  1. Power Query: import and reshapePlanned
    Load, clean, unpivot and merge, once, then refresh forever. The biggest single win here.
  2. The data model, Power Pivot and DAXPlanned
    Relationships between tables, and measures. Windows only.
  3. LAMBDA and LETPlanned
    Writing your own reusable functions without leaving the formula bar. Microsoft 365 only.
  4. AutomationPlanned
    Office Scripts, VBA and Python in Excel. Which to reach for, and when not to.
  5. Performance and the calculation enginePlanned
    Why a workbook goes slow. Volatile functions, whole-column references, calculation order.
  6. Sharing, protecting and governingPlanned
    Locking inputs, versioning, and knowing when the answer is a real database.
