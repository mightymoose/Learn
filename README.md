# Learn

Lessons and reference cards built from books, one folder per subject.
`index.html` is a searchable index of everything.

## Layout

```
index.html          searchable index, React from a CDN, no build step
search-index.js     generated by tools/build-index.py, do not edit
search-filter.js    the matching logic, kept separate so it can be tested
<subject>/
  MISSION.md        why this subject is being learned
  RESOURCES.md      trusted sources, every link checked before it is added
  NOTES.md          working notes, page offsets, conventions
  GLOSSARY.md       canonical terms, added only once understood
  assets/           shared stylesheet and drill engine for this subject
  lessons/          NNNN-name.html, the teaching pages
  reference/        printable cards, the compressed version
  learning-records/ NNNN-name.md, decisions that steer future sessions
  sources/          the book itself, git-ignored
```

## Adding a page

Give it `learn:*` meta tags in the `<head>` so the index picks it up:

```html
<meta name="learn:subject" content="Algebra">
<meta name="learn:type"    content="lesson">
<meta name="learn:source"  content="Lang, Algebra (GTM 211)">
<meta name="learn:section" content="I &sect;1">
<meta name="learn:order"   content="1.01">
<meta name="learn:status"  content="current">
<meta name="learn:tags"    content="monoid, product notation">
```

`status` is `current`, or `ahead-of-sequence` for a card whose lesson has not
been written yet. The index badges those so they do not look like the next
thing to read.

Then run the checks, which rebuild the index first:

```sh
sh tools/check.sh
```

## Tools

| Command | What it does |
|---|---|
| `python3 tools/build-index.py` | Rebuild `search-index.js` from the pages |
| `python3 tools/check-pages.py` | Tags, links, absolute paths, SVG, drill integrity |
| `node tools/test-drills.js` | Clicks through every drill against the real engine |
| `node tools/test-search.js` | The index search, against the real data |
| `node tools/test-app.js` | Runs the real index app and checks what it renders |
| `sh tools/check.sh` | All of the above |

Python 3 and Node are the only requirements. There are no packages to install.

## Viewing

Open `index.html` directly, or serve the folder:

```sh
python3 -m http.server 8000
```
